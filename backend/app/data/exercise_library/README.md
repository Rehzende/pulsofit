# Exercise library seed data

Raw exercise catalog data (name, category, equipment, muscle groups, PT-BR translations). Not currently wired into an automated import — kept here as reference/seed data for the `ExerciseLibrary` model rather than loose at the repo root.

- `exercises_pt.json` — full catalog, Portuguese
- `minified-exercises.json` / `minified-exercises-pt-br.json` — minified variants
